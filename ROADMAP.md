# Product roadmap

This roadmap reflects the current first-release direction. The workflow and
acceptance rules for implementation are defined in the [first-release workflow
contract](docs/first-release-workflow.md) (**proposed for review**).

1. Public deterministic demo of the task-to-handoff journey.
2. Private personal workspaces with saved tasks, pasted repository context,
   and manual implementation and validation evidence.
3. AI-assisted planning within the task workflow.

Code execution, GitHub connection, CI-result ingestion, team invitations,
billing, and production backend rollout are deferred beyond this release.
